# Corpus README

`corpus.csv` — shows 113 screened documents, 107 included / 6 excluded, links out to each by DOI/URL.

`Inclusion_Protocol.xlsx` — the five-check screening workbook behind the include/exclude split, with a sheet for each area covered in the document.

`First_Build/` — the original database build: `build_log.txt`, `build_vectorised_database.py`, `figure_captions_cache.json`.

`Rebuild/` — the rebuilt database with the correction made (v5): `build_log_v5.txt`, `database_build_v5.py`, `figure_captions_cache.json`.
