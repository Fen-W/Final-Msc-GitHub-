Testing README

The 6 scripts in this section were used for testing and all produce an _output.txt.

compare_databases.py — compares and count the faults between the two database build.

check_figure_caption.py — prints the vision models deception of a specific picture and 
what is actually on that page. To show the vision models fault with clarity 

check_figure_caption_v5.py — the same with the rebuilt database for comparison.

check_retrieval_quality.py — how much expected  of the evidence was found. If long
documents crowd out short ones.

check_systems_match.py — checks System 1's own search still matches the shared one
used by the others as they are separate.
